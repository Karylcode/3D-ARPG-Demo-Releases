# 3D ARPG Demo（Windows 版）

第三人稱動作遊戲 Demo 的 Windows 試玩版。這裡只放打包好的遊戲，不放原始碼。

## 下載

1. 到 [Releases](../../releases/latest) 下載最新的 `3D-ARPG-Demo-vX.Y.Z-win64.zip`。
2. 下載完先在 zip 上按右鍵 → 內容 → 勾選「解除封鎖」→ 確定，再解壓縮。
3. 點 `Update.bat` 開遊戲。

需求：Windows 10 / 11，64 位元。

如果出現藍色的「Windows 已保護您的電腦」（SmartScreen），按「其他資訊」→「仍要執行」。遊戲沒有簽章，所以第一次會跳這個。

## 更新

之後每次都用 `Update.bat` 開遊戲：

- 會先查有沒有新版。有就自動下載、換檔，再開遊戲。
- 已經是最新版，或沒有網路，就直接開遊戲。
- 更新失敗會保留目前的版本，不會把遊戲弄壞。
- 更新時遊戲要先關掉。

想手動更新也可以：下載新版 zip，解壓縮覆蓋舊資料夾。
